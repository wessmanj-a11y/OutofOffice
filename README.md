# OUT OF OFFICE

A satirical collectible card game about surviving corporate America.

## Core Concept
- Position Cards: Intern to CEO
- Memo Cards: workplace chaos
- PTO Cards: sanity-saving counters

## Win Conditions
1. Reach CEO
2. Escape the rat race by maximizing sanity/freedom

## Visual Direction
Unhinged corporate satire, collectible card aesthetic, absurd office humor.

## Build Roadmap
- Mobile-friendly web app
- Single-player vs AI
- Custom card art system
- Burnout meter
- Promotion ladder
- Deck builder

## Initial Art Sets
- Corporate Ladder Series
- HR Nightmare Series
- PTO Rebellion Series

This repository is the official build space for the game.
